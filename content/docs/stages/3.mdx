# مرحله ۳ — مدیریت فایل‌ها و نظم دیجیتال

بیشتر کاربران کامپیوتر دیر یا زود با این سؤال‌ها روبه‌رو می‌شوند: «فایلم کجا رفت؟»، «کدام نسخه جدیدتر است؟»، «چرا نمی‌توانم سندم را پیدا کنم؟» یا «آیا اشتباهی حذفش کردم؟»

مدیریت درست فایل‌ها کمک می‌کند این مشکل‌ها کمتر شوند. وقتی فایل‌هایت منظم باشند، سریع‌تر کار می‌کنی، استرس کمتری داری و برای کارهای جدی‌تر آماده‌تر می‌شوی.

## در پایان این مرحله چه کاری می‌توانی انجام بدهی؟

بعد از تمرین‌های این مرحله، باید بتوانی:

- توضیح بدهی فایل و پوشه چیست.
- با File Explorer راحت‌تر کار کنی.
- پوشه‌های اصلی Windows مثل Desktop، Documents، Downloads و Pictures را بشناسی.
- فایل‌ها را بسازی، نام‌گذاری کنی، کپی کنی، جابه‌جا کنی و حذف کنی.
- پسوندهای رایج فایل‌ها را بشناسی.
- فایل حذف‌شده را از Recycle Bin برگردانی.
- پوشه‌ی Downloads را مرتب نگه داری.
- فایل ZIP بسازی و فایل ZIP را Extract کنی.
- فایل‌ها را با Search پیدا کنی.
- Properties یک فایل را ببینی.
- یک ساختار مرتب و حرفه‌ای برای فایل‌های شخصی، کاری و آموزشی بسازی.

## بهترین روش یادگیری در این مرحله

- با فایل‌های تمرینی کار کن تا اگر اشتباه شد، نگران فایل‌های مهم نباشی.
- برای هر فایل اسم واضح بگذار.
- فایل‌ها را روی Desktop رها نکن؛ برای آن‌ها پوشه‌ی مناسب بساز.
- بعد از دانلود، فایل را بررسی کن و به جای درست منتقل کن.
- قبل از حذف فایل، یک لحظه فکر کن که آیا واقعاً به آن نیاز نداری.

---

# درس ۱ — فایل چیست؟

فایل یک آیتم دیجیتال است که اطلاعات را داخل خود نگه می‌دارد.

مثال‌ها:

| نوع فایل | کاربرد |
| --- | --- |
| Document | متن، نامه، گزارش یا رزومه |
| Photo | عکس و تصویر |
| Video | فیلم یا ویدیو |
| Music | صدا یا موسیقی |
| Spreadsheet | جدول، عدد، حساب‌وکتاب و فرمول |

## مثال ساده

فایل را مثل یک برگه‌ی کاغذ تصور کن. هر برگه می‌تواند یک چیز مشخص داشته باشد:

- رزومه
- نامه
- عکس
- فاکتور
- یادداشت

در کامپیوتر هم هر بخش از اطلاعات معمولاً داخل یک فایل ذخیره می‌شود.

## تمرین

روی کامپیوتر خودت چند فایل پیدا کن و نوع آن‌ها را حدس بزن:

- آیا متن است؟
- آیا عکس است؟
- آیا ویدیو است؟
- آیا جدول یا فایل کاری است؟

## بهترین روش

وقتی با فایل‌ها کار می‌کنی، فقط به آیکون نگاه نکن. اسم فایل، محل ذخیره و پسوند آن هم کمک می‌کند بفهمی فایل چیست.

---

# درس ۲ — پوشه چیست؟

پوشه یا Folder یک ظرف برای مرتب کردن فایل‌هاست. پوشه کمک می‌کند فایل‌هایت را دسته‌بندی کنی و بعداً راحت‌تر پیدایشان کنی.

پوشه را مثل یک پوشه‌ی واقعی داخل کمد یا کشو تصور کن. اگر همه‌ی برگه‌ها روی میز پخش باشند، پیدا کردن یک برگه سخت می‌شود. اما اگر هر دسته در پوشه‌ی خودش باشد، کار ساده‌تر است.

## نمونه‌ی ساختار ساده

```text
Documents
├── Work
├── Personal
├── School
└── Finance
```

## تمرین

یک پوشه به نام `Practice` بساز و داخل آن این پوشه‌ها را ایجاد کن:

```text
Practice
├── Photos
├── Documents
└── Downloads
```

## بهترین روش

برای پوشه‌ها اسم‌های کوتاه، واضح و قابل فهم انتخاب کن. مثلاً `Finance` یا `مالی` بهتر از `New Folder` است.

---

# درس ۳ — آشنایی با File Explorer

File Explorer برنامه‌ی اصلی Windows برای دیدن و مدیریت فایل‌ها و پوشه‌هاست.

برای باز کردن آن می‌توانی از این میانبر استفاده کنی:

```text
Windows + E
```

یا از مسیر:

```text
Start → File Explorer
```

## بخش‌های اصلی File Explorer

### Navigation Pane

بخش سمت چپ File Explorer است و معمولاً مسیرهای مهم را نشان می‌دهد:

- Quick Access
- Desktop
- Downloads
- Documents
- Pictures
- Drives

### Address Bar

محل فعلی تو را نشان می‌دهد.

مثال:

```text
This PC > Documents > Work
```

### Main Content Area

بخش اصلی پنجره است که فایل‌ها و پوشه‌های مسیر فعلی را نشان می‌دهد.

## تمرین

در File Explorer به این بخش‌ها برو:

- Desktop
- Documents
- Downloads
- Pictures

بعد از خودت بپرس: «الان دقیقاً کجا هستم؟»

## بهترین روش

همیشه به Address Bar نگاه کن. این بخش به تو می‌گوید الان در کدام پوشه هستی و کمک می‌کند بین مسیرها گم نشوی.

---

# درس ۴ — پوشه‌های رایج Windows

## Desktop

همان صفحه‌ای است که بعد از ورود می‌بینی. برای میانبرها و فایل‌های موقت خوب است، اما نباید همه چیز را روی Desktop نگه داری.

## Documents

جای مناسب برای:

- نامه‌ها
- یادداشت‌ها
- گزارش‌ها
- فایل‌های PDF
- فایل‌های کاری و درسی

## Downloads

فایل‌هایی که از اینترنت دانلود می‌کنی معمولاً اینجا ذخیره می‌شوند. این پوشه خیلی زود شلوغ می‌شود و باید مرتب تمیز شود.

## Pictures

برای عکس‌ها و تصاویر استفاده می‌شود.

## Videos

برای ویدیوها استفاده می‌شود.

## Music

برای فایل‌های صوتی و موسیقی استفاده می‌شود.

## تمرین

هر پوشه را باز کن و ببین داخل آن چه چیزهایی وجود دارد. اگر فایلی را نمی‌شناسی، حذفش نکن؛ فقط اسم و نوع آن را بررسی کن.

## بهترین روش

Downloads جای نگهداری دائمی فایل‌ها نیست. بعد از دانلود، فایل مهم را به پوشه‌ی مناسب منتقل کن.

---

# درس ۵ — نام‌گذاری فایل‌ها

اسم خوب باعث می‌شود بعداً فایل را سریع‌تر پیدا کنی.

نام نامناسب:

```text
New Document.docx
```

نام بهتر:

```text
Resume_Ali_2026.docx
```

نام نامناسب:

```text
Image1.jpg
```

نام بهتر:

```text
Vacation_Berlin_May2026.jpg
```

## قانون‌های ساده

استفاده کن از:

- اسم‌های واضح
- تاریخ، وقتی مفید است
- قالب ثابت برای فایل‌های مشابه

پرهیز کن از:

- اسم‌های تصادفی
- اسم‌های خیلی طولانی
- اسم‌هایی مثل `final_final_new_2`

## تمرین

سه فایل تمرینی بساز و برای هرکدام اسم واضح انتخاب کن. بعد از خودت بپرس: «اگر سه ماه دیگر این فایل را ببینم، می‌فهمم چیست؟»

## بهترین روش

برای فایل‌های مهم، اسم را طوری انتخاب کن که بدون باز کردن فایل هم موضوع آن مشخص باشد.

---

# درس ۶ — پسوند فایل‌ها

پسوند فایل نشان می‌دهد فایل از چه نوعی است.

مثال:

```text
Resume.docx
```

پسوند این فایل:

```text
.docx
```

## پسوندهای رایج

### سندها

| پسوند | نوع فایل |
| --- | --- |
| `.docx` | سند Word |
| `.pdf` | سند PDF |
| `.txt` | فایل متنی ساده |

### عکس‌ها

| پسوند | نوع فایل |
| --- | --- |
| `.jpg` | تصویر |
| `.png` | تصویر |
| `.gif` | تصویر متحرک |

### صدا

| پسوند | نوع فایل |
| --- | --- |
| `.mp3` | فایل صوتی |
| `.flac` | فایل صوتی با کیفیت بالا |
| `.wav` | فایل صوتی |

### ویدیو

| پسوند | نوع فایل |
| --- | --- |
| `.mp4` | ویدیو |
| `.mkv` | ویدیو |
| `.avi` | ویدیو |

### فایل‌های فشرده

| پسوند | نوع فایل |
| --- | --- |
| `.zip` | فایل فشرده |
| `.rar` | فایل فشرده |
| `.7z` | فایل فشرده |

## تمرین

پسوند ۱۰ فایل مختلف را روی کامپیوترت بررسی کن و بگو هر فایل چه نوعی دارد.

## بهترین روش

پسوند فایل را بی‌دلیل تغییر نده. عوض کردن پسوند معمولاً نوع واقعی فایل را تغییر نمی‌دهد و ممکن است باعث شود فایل درست باز نشود.

---

# درس ۷ — ساخت فایل و پوشه

## ساخت پوشه

1. در فضای خالی کلیک راست کن.
2. گزینه‌ی New را انتخاب کن.
3. Folder را انتخاب کن.
4. اسم پوشه را وارد کن.

## ساخت فایل متنی

1. در فضای خالی کلیک راست کن.
2. گزینه‌ی New را انتخاب کن.
3. Text Document را انتخاب کن.
4. اسم فایل را وارد کن.

## تمرین

این ساختار را بساز:

```text
Computer Training
├── Notes
├── Photos
└── Practice Files
```

داخل `Notes` یک فایل متنی تمرینی بساز.

## بهترین روش

بعد از ساخت پوشه یا فایل، همان لحظه اسم مناسب بگذار. اگر همه چیز با `New Folder` و `New Text Document` بماند، بعداً پیدا کردن فایل‌ها سخت می‌شود.

---

# درس ۸ — Copy و Move

## Copy چیست؟

Copy یعنی یک نسخه‌ی جدید از فایل ساخته می‌شود و فایل اصلی سر جای خودش باقی می‌ماند.

میانبر:

```text
Ctrl + C
Ctrl + V
```

## Move چیست؟

Move یعنی فایل از جای قبلی برداشته می‌شود و به جای جدید منتقل می‌شود.

میانبر:

```text
Ctrl + X
Ctrl + V
```

## مثال

فایل اصلی:

```text
Downloads
└── Resume.pdf
```

بعد از Copy:

```text
Downloads
└── Resume.pdf

Documents
└── Resume.pdf
```

بعد از Move:

```text
Documents
└── Resume.pdf
```

## تمرین

- یک فایل تمرینی را Copy کن.
- یک فایل تمرینی دیگر را Move کن.
- نتیجه را مقایسه کن و بگو کدام فایل در چند جا وجود دارد.

## بهترین روش

اگر مطمئن نیستی فایل باید فقط جابه‌جا شود یا یک نسخه‌ی اضافه لازم داری، اول Copy امن‌تر است. بعداً اگر لازم نبود، نسخه‌ی اضافه را حذف کن.

---

# درس ۹ — تغییر نام فایل‌ها

تغییر نام باعث می‌شود فایل‌ها راحت‌تر پیدا شوند.

روش‌ها:

- روی فایل کلیک راست کن و Rename را انتخاب کن.
- یا فایل را انتخاب کن و کلید `F2` را بزن.

## تمرین

این نام را:

```text
Document1.docx
```

به این نام تغییر بده:

```text
Monthly_Report_May_2026.docx
```

## بهترین روش

هنگام Rename فقط اسم فایل را تغییر بده و مراقب پسوند باش. اگر پسوند نمایش داده می‌شود، آن را اشتباهی حذف یا تغییر نده.

---

# درس ۱۰ — حذف فایل‌ها

## Delete

وقتی فایل را Delete می‌کنی، معمولاً به Recycle Bin منتقل می‌شود.

میانبر:

```text
Delete
```

## حذف دائمی

میانبر:

```text
Shift + Delete
```

این روش را با احتیاط استفاده کن؛ چون فایل معمولاً وارد Recycle Bin نمی‌شود.

## تمرین

- یک فایل تمرینی را Delete کن.
- Recycle Bin را باز کن.
- فایل را پیدا کن.
- آن را Restore کن.

## بهترین روش

برای تمرین حذف، فقط از فایل‌های تمرینی استفاده کن. فایل‌های مهم را بدون فکر حذف نکن.

---

# درس ۱۱ — Recycle Bin

Recycle Bin محل نگهداری موقت فایل‌های حذف‌شده است و به تو فرصت می‌دهد بعضی فایل‌ها را برگردانی.

## کارهای مهم

### Restore

فایل را به محل قبلی خودش برمی‌گرداند.

### Empty Recycle Bin

محتوای Recycle Bin را برای همیشه حذف می‌کند.

## تمرین

- یک فایل تمرینی را Delete کن.
- یک پوشه‌ی تمرینی را Delete کن.
- هر دو را از Recycle Bin برگردان.

## بهترین روش

قبل از Empty Recycle Bin، سریع نگاهی به فایل‌های داخل آن بینداز. شاید چیزی اشتباهی حذف شده باشد.

---

# درس ۱۲ — مدیریت Downloads

وقتی فایلی از اینترنت دانلود می‌کنی، معمولاً وارد این پوشه می‌شود:

```text
Downloads
```

## عادت خوب بعد از دانلود

1. فایل را باز کن و مطمئن شو همان چیزی است که می‌خواستی.
2. اگر مهم است، آن را به پوشه‌ی مناسب منتقل کن.
3. اگر لازم نیست، حذفش کن.

به جای این:

```text
Downloads
├── 500 random files
```

از این نظم استفاده کن:

```text
Documents
└── Work

Pictures
└── Travel

Music
└── Albums
```

## تمرین

پوشه‌ی Downloads را باز کن و فایل‌های تمرینی یا غیرمهم را دسته‌بندی کن. فایل‌های مهم را بدون اطمینان حذف نکن.

## بهترین روش

هفته‌ای یک بار Downloads را مرتب کن. این کار کوچک جلوی شلوغی بزرگ را می‌گیرد.

---

# درس ۱۳ — فایل‌های ZIP

ZIP فایلی است که چند فایل یا پوشه را داخل یک بسته قرار می‌دهد.

مثال:

```text
Photos.zip
```

## چرا از ZIP استفاده می‌کنیم؟

- ارسال چند فایل راحت‌تر می‌شود.
- گاهی حجم فایل‌ها کمتر می‌شود.
- فایل‌ها مرتب‌تر و یک‌جا نگه داشته می‌شوند.

## Extract کردن فایل ZIP

روی فایل ZIP کلیک راست کن و گزینه‌ی زیر را انتخاب کن:

```text
Extract All
```

## ساخت فایل ZIP

روی فایل‌ها یا پوشه‌های موردنظر کلیک راست کن و گزینه‌ای شبیه این را انتخاب کن:

```text
Compress to ZIP File
```

## تمرین

- چند فایل تمرینی را انتخاب کن.
- از آن‌ها یک ZIP بساز.
- فایل ZIP را در یک پوشه‌ی دیگر Extract کن.
- بررسی کن فایل‌ها درست خارج شده‌اند.

## بهترین روش

قبل از ارسال فایل ZIP، آن را یک بار باز کن و مطمئن شو فایل‌های درست داخل آن قرار دارند.

---

# درس ۱۴ — جست‌وجوی فایل‌ها

اگر فایل را پیدا نمی‌کنی، Search می‌تواند کمک کند.

## جست‌وجو در File Explorer

File Explorer را باز کن و در کادر Search نام فایل یا بخشی از آن را تایپ کن:

```text
invoice
```

Windows فایل‌هایی را که با این عبارت هماهنگ باشند پیدا می‌کند.

## جست‌وجو با پسوند

برای پیدا کردن همه‌ی PDFها:

```text
*.pdf
```

برای پیدا کردن همه‌ی عکس‌های JPG:

```text
*.jpg
```

## تمرین

با Search این موارد را پیدا کن:

- همه‌ی فایل‌های PDF
- همه‌ی فایل‌های JPG
- یک سند مشخص با بخشی از نام آن

## بهترین روش

اگر نام دقیق فایل را یادت نیست، بخشی از اسم، نوع فایل یا پوشه‌ای را که احتمالاً داخل آن است امتحان کن.

---

# درس ۱۵ — Properties فایل

Properties اطلاعات یک فایل را نشان می‌دهد.

برای دیدن آن:

```text
Right-click → Properties
```

## چه اطلاعاتی می‌بینی؟

- Size یا حجم فایل
- Date created یا تاریخ ساخت
- Date modified یا تاریخ آخرین تغییر
- File type یا نوع فایل
- Location یا محل ذخیره

## تمرین

Properties این فایل‌ها را بررسی کن:

- یک PDF
- یک عکس
- یک ویدیو

بعد حجم و محل ذخیره‌ی هرکدام را با هم مقایسه کن.

## بهترین روش

وقتی چند نسخه از یک فایل داری، Date modified می‌تواند کمک کند بفهمی کدام نسخه جدیدتر است.

# درس ۱۶ — ساختار حرفه‌ای پوشه‌ها

یک ساختار خوب باعث می‌شود فایل‌ها سریع‌تر پیدا شوند و پشتیبان‌گیری هم راحت‌تر باشد.

## ساختار پیشنهادی

```text
Documents
├── Work
│   ├── Projects
│   ├── Reports
│   └── Invoices
│
├── Personal
│   ├── IDs
│   ├── Finance
│   └── Travel
│
└── Learning
    ├── Courses
    ├── Notes
    └── Certificates
```

## مزیت‌ها

- جست‌وجوی راحت‌تر
- پشتیبان‌گیری بهتر
- شلوغی کمتر
- ظاهر حرفه‌ای‌تر
- آمادگی بهتر برای کار و تحصیل

## تمرین

یک نسخه‌ی ساده از این ساختار را برای خودت بساز. اگر لازم است، اسم پوشه‌ها را فارسی انتخاب کن:

```text
اسناد
├── کار
├── شخصی
└── یادگیری
```

## بهترین روش

ساختار پوشه‌ها باید ساده بماند. اگر برای پیدا کردن فایل باید وارد ۱۰ پوشه شوی، ساختار بیش از حد پیچیده شده است.

# تمرین ترکیبی مرحله ۳

تلاش کن با کمترین کمک این کارها را انجام بدهی:

1. File Explorer را باز کن.
2. وارد Documents شو.
3. یک پوشه به نام `Computer Practice` بساز.
4. داخل آن سه پوشه‌ی `Notes`، `Photos` و `Reports` بساز.
5. یک فایل متنی تمرینی داخل `Notes` بساز.
6. نام فایل را واضح‌تر کن.
7. فایل را Copy کن و نسخه‌ی دوم را داخل `Reports` بگذار.
8. یک فایل تمرینی دیگر را Move کن.
9. یک فایل را Delete کن.
10. فایل حذف‌شده را از Recycle Bin برگردان.
11. چند فایل را ZIP کن.
12. فایل ZIP را Extract کن.
13. با Search یک فایل PDF یا JPG پیدا کن.
14. Properties یک فایل را باز کن و حجم و محل آن را ببین.

# چک‌لیست عملی مرحله ۳

وقتی کنار هر مورد بتوانی تیک بزنی، یعنی مرحله ۳ را خوب تمرین کرده‌ای:

- [ ] پسوند فایل‌ها را تشخیص می‌دهم.
- [ ] فایل‌ها را Rename می‌کنم.
- [ ] فایل‌ها را Copy می‌کنم.
- [ ] فایل‌ها را Move می‌کنم.
- [ ] فایل‌ها را Delete می‌کنم.
- [ ] فایل حذف‌شده را Restore می‌کنم.

- [ ] Downloads را مرتب می‌کنم.
- [ ] فایل ZIP می‌سازم.
- [ ] فایل ZIP را Extract می‌کنم.
- [ ] با Search فایل پیدا می‌کنم.

# پروژه‌ی پایانی مرحله ۳

برای پایان این مرحله، این ساختار را بساز:

```text
Documents
├── Personal
│   ├── Photos
│   ├── Finance
│   └── IDs
│
├── Work
│   ├── Projects
│   └── Reports
│
└── Learning
    ├── Courses
    └── Notes
```

بعد این کارها را انجام بده:

1. پنج فایل نمونه بساز.
2. اسم همه‌ی فایل‌ها را مناسب و واضح کن.
3. فایل‌ها را به پوشه‌های درست منتقل کن.
4. یک فایل را به محل دوم Copy کن.
5. یک فایل را Delete کن.
6. همان فایل را از Recycle Bin برگردان.
7. یک فایل ZIP بساز.
8. فایل ZIP را Extract کن.
9. یک فایل مشخص را با Search پیدا کن.
10. Properties همان فایل را بررسی کن.

## معیار قبولی

مرحله ۳ را زمانی با موفقیت تمام کرده‌ای که بتوانی:

- فایل‌ها را با اعتمادبه‌نفس مرتب کنی.
- بدانی فایل‌ها کجا ذخیره شده‌اند.
- بدون کمک در File Explorer حرکت کنی.
- فایل حذف‌شده را از Recycle Bin برگردانی.
- از ZIP برای بسته‌بندی و خارج کردن فایل‌ها استفاده کنی.
- فایل‌ها را سریع با Search پیدا کنی.
- یک ساختار تمیز و حرفه‌ای برای فایل‌های شخصی، کاری و آموزشی نگه داری.
