# مرحله ۲ — کار با ویندوز و مدیریت محیط

Windows محیط اصلی کار تو با کامپیوتر است. هرچه بهتر آن را بشناسی، راحت‌تر می‌توانی برنامه‌ها را پیدا کنی، فایل‌ها را باز کنی، تنظیمات ساده را تغییر بدهی و چند کار را هم‌زمان انجام بدهی.

هدف این مرحله این نیست که همه‌ی تنظیمات ویندوز را حفظ کنی. هدف این است که بدانی برای کارهای روزمره از کجا شروع کنی و وقتی چیزی را پیدا نمی‌کنی، از ابزارهای درست مثل Start و Search کمک بگیری.

## در پایان این مرحله چه کاری می‌توانی انجام بدهی؟

بعد از تمرین‌های این مرحله، باید بتوانی:

- بخش‌های اصلی دسکتاپ و Taskbar را بشناسی.
- از Start Menu و Search برای پیدا کردن برنامه‌ها، فایل‌ها و تنظیمات استفاده کنی.
- پنجره‌ها را Minimize، Maximize، Restore، Move، Resize و Close کنی.
- بین چند برنامه‌ی باز جابه‌جا شوی.
- برنامه‌های پرکاربرد را به Taskbar سنجاق کنی و برداری.
- اعلان‌ها و تنظیمات سریع را بررسی کنی.
- Settings را باز کنی و بخش‌های مهم آن را پیدا کنی.
- ظاهر Windows مثل تصویر پس‌زمینه، رنگ و Light یا Dark Mode را تغییر بدهی.
- برنامه‌ها را از منبع امن نصب و حذف کنی.
- مفهوم حساب کاربری و دسترسی Administrator را در سطح پایه بفهمی.
- هشدارهای امنیتی Windows را جدی بگیری.

## بهترین روش یادگیری در این مرحله

- هر درس را روی کامپیوتر واقعی تمرین کن.
- اگر پیدا کردن چیزی زمان برد، عجله نکن؛ Search را امتحان کن.
- تغییرات مهم را آرام انجام بده و قبل از کلیک، متن صفحه را بخوان.
- فقط تنظیماتی را تغییر بده که می‌دانی چه کاری انجام می‌دهند.
- بعد از هر تمرین از خودت بپرس: «اگر دوباره تنها باشم، می‌توانم این کار را انجام بدهم؟»

# مقدمه — Windows چیست؟

Windows یک سیستم‌عامل است. سیستم‌عامل برنامه‌ی اصلی کامپیوتر است که کمک می‌کند با سخت‌افزار، فایل‌ها، برنامه‌ها و اینترنت کار کنی.

بدون سیستم‌عامل، کامپیوتر برای ما قابل استفاده نیست؛ چون نمی‌توانیم برنامه‌ها را راحت اجرا کنیم، فایل‌ها را ببینیم یا با ماوس و کیبورد کار کنیم.

## Windows چه کارهایی انجام می‌دهد؟

Windows:

- دسکتاپ را نمایش می‌دهد.
- برنامه‌ها را اجرا می‌کند.
- فایل‌ها و پوشه‌ها را مدیریت می‌کند.
- ارتباط با ماوس، کیبورد، پرینتر، هدفون و دستگاه‌های دیگر را برقرار می‌کند.
- اتصال به اینترنت و شبکه را مدیریت می‌کند.
- تنظیمات صدا، تصویر، زبان، حساب کاربری و امنیت را در اختیار تو می‌گذارد.
- از کامپیوتر در برابر بسیاری از تهدیدهای رایج محافظت می‌کند.

## مثال ساده

Windows را مثل مدیر یک ساختمان تصور کن. برنامه‌ها مثل اتاق‌های مختلف هستند، فایل‌ها مثل وسایل داخل اتاق‌ها، و سخت‌افزارها مثل برق، آسانسور و درها. Windows کمک می‌کند همه‌ی این بخش‌ها با هم درست کار کنند.

---

# درس ۱ — دسکتاپ Windows

Desktop صفحه‌ی اصلی Windows است که بعد از ورود به حساب کاربری می‌بینی. این صفحه مثل میز کار توست؛ چیزهایی که زیاد استفاده می‌کنی معمولاً آنجا قرار می‌گیرند.

## بخش‌های اصلی دسکتاپ

### تصویر پس‌زمینه

عکس یا رنگی است که پشت آیکون‌ها دیده می‌شود. می‌توانی آن را تغییر بدهی.

### آیکون‌ها

آیکون‌ها تصویرهای کوچکی هستند که می‌توانند برنامه، فایل، پوشه یا میانبر باشند.

مثال‌ها:

- Recycle Bin
- This PC
- File Explorer
- Google Chrome
- Microsoft Edge
- پوشه‌های شخصی

### Taskbar

Taskbar معمولاً پایین صفحه است و برای دسترسی سریع به برنامه‌ها و بخش‌های مهم Windows استفاده می‌شود.

در Taskbar معمولاً این موارد را می‌بینی:

- دکمه‌ی Start
- Search
- برنامه‌های سنجاق‌شده
- برنامه‌های باز
- آیکون صدا
- آیکون شبکه یا Wi-Fi
- ساعت و تاریخ
- بخش اعلان‌ها

## تمرین

روی صفحه‌ی خودت این موارد را نشان بده:

- تصویر پس‌زمینه
- چند آیکون دسکتاپ
- Taskbar
- دکمه‌ی Start
- ساعت
- آیکون صدا
- آیکون اینترنت
- بخش اعلان‌ها

## بهترین روش

دسکتاپ را خیلی شلوغ نکن. بهتر است فقط میانبرها یا فایل‌های واقعاً پرکاربرد روی دسکتاپ باشند. فایل‌های مهم را در پوشه‌های منظم مثل Documents نگه دار.

---

# درس ۲ — Start Menu

Start Menu مرکز اصلی برای پیدا کردن برنامه‌ها، تنظیمات و ابزارهای Windows است.

برای باز کردن آن می‌توانی:

- روی دکمه‌ی Start کلیک کنی.
- کلید Windows روی کیبورد را فشار بدهی.

## Start Menu چه چیزهایی دارد؟

- Search برای جست‌وجوی سریع برنامه‌ها، فایل‌ها و تنظیمات
- فهرست برنامه‌های نصب‌شده
- برنامه‌هایی مثل Calculator، Notepad، Paint، Settings، Photos و File Explorer
- Power Menu برای Sleep، Restart و Shut down

## آموزش قدم‌به‌قدم

1. روی Start کلیک کن.
2. چند برنامه‌ی پیشنهادی را ببین.
3. بخش Search را امتحان کن.
4. نام `Calculator` را تایپ کن.
5. برنامه را باز کن.
6. دوباره Start را باز کن.
7. این بار `Notepad` را پیدا و اجرا کن.
8. Power Menu را فقط مشاهده کن و گزینه‌ها را بشناس.

## تمرین

با Start Menu این برنامه‌ها را پیدا و اجرا کن:

- Calculator
- Notepad
- Paint
- Settings
- File Explorer

## بهترین روش

اگر نمی‌دانی یک برنامه کجاست، از Start Menu و Search شروع کن. جست‌وجو معمولاً سریع‌تر از گشتن در منوهاست.

---

# درس ۳ — جست‌وجو در Windows

Search کمک می‌کند برنامه‌ها، تنظیمات و فایل‌ها را سریع پیدا کنی. خیلی وقت‌ها کاربران باتجربه به جای گشتن در چند منو، اول Search را امتحان می‌کنند.

## استفاده از Search

روش ساده:

1. کلید Windows را فشار بده.
2. شروع به تایپ کن.
3. نتیجه‌ی مناسب را انتخاب کن.

مثال:

```text
calculator
```

یا:

```text
bluetooth
```

## Search چه چیزهایی را پیدا می‌کند؟

برنامه‌ها:

- Chrome
- Word
- Paint
- Calculator

فایل‌ها:

- `Resume.docx`
- `Budget.xlsx`
- `Photo.jpg`

تنظیمات:

- Bluetooth
- Wi-Fi
- Display
- Sound
- Windows Update

## تمرین

با Search این موارد را پیدا کن:

- Calculator
- Paint
- Bluetooth Settings
- Display Settings
- Task Manager
- Windows Update

## بهترین روش

لازم نیست نام کامل را تایپ کنی. معمولاً با چند حرف اول، Windows نتیجه‌ی درست را پیشنهاد می‌دهد. اگر نتیجه اشتباه بود، کلمه را واضح‌تر تایپ کن.

---

# درس ۴ — پنجره‌ها در Windows

Window یا پنجره، فضایی است که یک برنامه داخل آن اجرا می‌شود.

مثال‌ها:

- پنجره‌ی مرورگر
- پنجره‌ی File Explorer
- پنجره‌ی Settings
- پنجره‌ی Notepad

## دکمه‌های اصلی پنجره

- Minimize: پنجره را از صفحه جمع می‌کند و به Taskbar می‌فرستد. برنامه هنوز باز است.
- Maximize: پنجره را بزرگ می‌کند تا کل صفحه را بگیرد.
- Restore: پنجره‌ی بزرگ‌شده را دوباره به اندازه‌ی کوچک‌تر برمی‌گرداند.
- Close: برنامه یا پنجره را می‌بندد.

## جابه‌جا کردن و تغییر اندازه‌ی پنجره

برای جابه‌جا کردن:

1. روی نوار بالای پنجره کلیک کن و نگه دار.
2. پنجره را به جای دلخواه بکش.
3. ماوس را رها کن.

برای تغییر اندازه:

1. نشانگر را روی لبه یا گوشه‌ی پنجره ببر.
2. وقتی شکل نشانگر تغییر کرد، کلیک کن و بکش.

## تمرین

چند برنامه را باز کن و برای هرکدام این کارها را انجام بده:

- Minimize
- Maximize
- Restore
- Move
- Resize
- Close

## بهترین روش

اگر برنامه را Minimize کردی و گم شد، نگران نشو. برنامه هنوز باز است و معمولاً از روی Taskbar می‌توانی دوباره آن را بیاوری.

---

# درس ۵ — کار با چند برنامه هم‌زمان

Multitasking یعنی چند برنامه را هم‌زمان باز نگه داری و بین آن‌ها جابه‌جا شوی.

مثال:

- مرورگر برای جست‌وجو
- Notepad برای یادداشت
- Calculator برای حساب کردن
- File Explorer برای مدیریت فایل‌ها

## روش‌های جابه‌جایی بین برنامه‌ها

### روش ۱: Taskbar

روی آیکون برنامه‌ی باز در Taskbar کلیک کن.

### روش ۲: Alt + Tab

کلیدهای زیر را بزن:

```text
Alt + Tab
```

با این میانبر می‌توانی بین برنامه‌های باز جابه‌جا شوی.

### روش ۳: کنار هم گذاشتن پنجره‌ها

1. یک پنجره را به سمت چپ صفحه بکش.
2. پنجره‌ی دیگر را به سمت راست صفحه بکش.
3. هر دو را هم‌زمان ببین.

## تمرین

این برنامه‌ها را باز کن:

- Calculator
- Notepad
- Paint
- مرورگر وب

بعد:

- با Taskbar بین آن‌ها جابه‌جا شو.
- با `Alt + Tab` بین آن‌ها جابه‌جا شو.
- دو پنجره را کنار هم قرار بده.
- برنامه‌های اضافه را ببند.

## بهترین روش

برنامه‌های خیلی زیاد را بی‌دلیل باز نگه ندار. این کار ممکن است کامپیوتر را کند کند و تمرکز را پایین بیاورد.

---

# درس ۶ — استفاده‌ی بهتر از Taskbar

Taskbar دسترسی سریع به برنامه‌ها، برنامه‌های باز و اطلاعات مهم سیستم را فراهم می‌کند.

با Taskbar می‌توانی:

- برنامه‌های باز را ببینی.
- سریع بین برنامه‌ها جابه‌جا شوی.
- برنامه‌های پرکاربرد را سنجاق کنی.
- وضعیت صدا، اینترنت و باتری را بررسی کنی.
- ساعت و اعلان‌ها را ببینی.

## Pin کردن برنامه‌ها

Pin کردن یعنی برنامه را روی Taskbar نگه داری تا همیشه سریع در دسترس باشد.

برنامه‌های مناسب برای Pin:

- مرورگر وب
- File Explorer
- Word یا Google Docs shortcut
- Calculator
- برنامه‌های کاری روزانه

## روش Pin کردن

1. برنامه را باز کن.
2. روی آیکون برنامه در Taskbar کلیک راست کن.
3. گزینه‌ی `Pin to taskbar` را انتخاب کن.

## روش Unpin کردن

1. روی آیکون برنامه در Taskbar کلیک راست کن.
2. گزینه‌ی `Unpin from taskbar` را انتخاب کن.

## تمرین

این برنامه‌ها را Pin کن:

- مرورگر
- File Explorer
- Calculator

بعد:

- هرکدام را از Taskbar باز کن.
- یکی را Unpin کن.
- دوباره آن را Pin کن.

## بهترین روش

فقط برنامه‌هایی را Pin کن که زیاد استفاده می‌کنی. Taskbar شلوغ باعث می‌شود پیدا کردن برنامه‌ها سخت‌تر شود.

---

# درس ۷ — اعلان‌ها و Notification Center

Notification پیام کوتاهی است که Windows یا برنامه‌ها برای اطلاع‌رسانی نمایش می‌دهند.

مثال‌ها:

- ایمیل جدید
- پایان دانلود
- اتصال فلش USB
- آماده بودن آپدیت
- هشدار امنیتی
- پیام از یک برنامه

## Notification Center چیست؟

Notification Center جایی است که اعلان‌های اخیر و بعضی تنظیمات سریع را نشان می‌دهد.

در نسخه‌های جدید Windows، با کلیک روی بخش ساعت یا آیکون‌های سمت راست Taskbar می‌توانی اعلان‌ها و تنظیمات سریع را ببینی.

## آموزش قدم‌به‌قدم

1. روی بخش اعلان‌ها یا ساعت در Taskbar کلیک کن.
2. اعلان‌های موجود را ببین.
3. اگر اعلانی مهم نیست، آن را پاک کن.
4. تنظیمات سریع مثل Wi-Fi، Bluetooth، صدا یا روشنایی را بررسی کن.
5. بدون تغییرهای مهم، فقط بخش‌ها را بشناس.

## تمرین

- Notification Center را باز کن.
- اعلان‌ها را بررسی کن.
- یک اعلان غیرمهم را ببند.
- تنظیمات سریع را ببین.
- دوباره پنل را ببند.

## بهترین روش

همه‌ی اعلان‌ها مهم نیستند، اما اعلان‌های امنیتی، آپدیت و خطاها را جدی‌تر بخوان. قبل از کلیک روی هر دکمه، متن پیام را آرام بررسی کن.

---

# درس ۸ — Settings در Windows

Settings برنامه‌ی اصلی برای تغییر تنظیمات Windows است.

از Settings می‌توانی مواردی مثل تصویر، صدا، اینترنت، دستگاه‌ها، ظاهر، حساب کاربری و آپدیت‌ها را مدیریت کنی.

## بخش‌های مهم Settings

- System: تنظیمات صفحه‌نمایش، صدا، حافظه، باتری و Power
- Bluetooth & devices: اتصال ماوس، کیبورد، هدفون، پرینتر و دستگاه‌های دیگر
- Network & Internet: Wi-Fi، اینترنت، VPN و تنظیمات شبکه
- Personalization: تصویر پس‌زمینه، رنگ‌ها، تم و ظاهر Windows
- Apps: دیدن، نصب، مدیریت و حذف برنامه‌ها
- Accounts: حساب کاربری، رمز ورود و روش‌های ورود
- Windows Update: بررسی و نصب آپدیت‌های Windows

## تمرین

Settings را باز کن و این بخش‌ها را فقط بررسی کن:

- Display
- Sound
- Bluetooth & devices
- Network & Internet
- Personalization
- Apps
- Windows Update

## بهترین روش

در Settings هر چیزی را که نمی‌شناسی تغییر نده. اول توضیح آن را بخوان یا نام گزینه را جست‌وجو کن. برای شروع، تمرکز روی تنظیمات ساده مثل صدا، تصویر، Wi-Fi و ظاهر کافی است.

---

# درس ۹ — شخصی‌سازی Windows

شخصی‌سازی کمک می‌کند محیط Windows برای چشم و سلیقه‌ی تو راحت‌تر باشد. این کار همچنین باعث می‌شود حس کنی محیط کامپیوتر قابل کنترل است.

## تغییر تصویر پس‌زمینه

1. Settings را باز کن.
2. وارد Personalization شو.
3. Background را انتخاب کن.
4. یک تصویر یا رنگ انتخاب کن.
5. نتیجه را روی دسکتاپ ببین.

## تغییر Theme

Theme می‌تواند رنگ‌ها، ظاهر پنجره‌ها و تصویر پس‌زمینه را تغییر دهد.

## حالت روشن و تاریک

Light Mode ظاهر روشن‌تر دارد.
Dark Mode ظاهر تیره‌تر دارد.

Dark Mode می‌تواند در محیط کم‌نور برای چشم راحت‌تر باشد و در بعضی دستگاه‌ها مصرف باتری را کمی کاهش دهد.

## تمرین

- تصویر پس‌زمینه را تغییر بده.
- یک رنگ مناسب برای Windows انتخاب کن.
- بین Light Mode و Dark Mode جابه‌جا شو.
- بعد از تغییرات، ظاهر دسکتاپ و پنجره‌ها را بررسی کن.

## بهترین روش

ظاهر Windows را زیبا کن، اما خوانایی را قربانی نکن. رنگ‌ها و تصویر پس‌زمینه نباید باعث شوند آیکون‌ها یا متن‌ها سخت دیده شوند.

# درس ۱۰ — نصب برنامه‌ها

نصب یا Installation یعنی یک نرم‌افزار را به کامپیوتر اضافه کنیم تا بتوانیم از آن استفاده کنیم.

مثال‌ها:

- نصب مرورگر
- نصب پخش‌کننده‌ی ویدیو
- نصب برنامه‌ی ویرایش عکس
- نصب ابزارهای کاری

## منابع امن برای نصب

بهترین منابع:

- سایت رسمی برنامه
- Microsoft Store
- لینک‌هایی که از منبع معتبر آمده‌اند

از این موارد دوری کن:

- سایت‌های دانلود ناشناس
- فایل‌هایی که از پیام‌های مشکوک آمده‌اند
- نسخه‌های کرک‌شده یا دستکاری‌شده
- نصب‌کننده‌هایی که چند برنامه‌ی اضافی همراه خود دارند

## مراحل معمول نصب

1. نام برنامه را جست‌وجو کن.
2. سایت رسمی برنامه را پیدا کن.
3. فایل نصب را دانلود کن.
4. فایل دانلودشده را اجرا کن.
5. پیام‌ها را با دقت بخوان.
6. گزینه‌های اضافی را بررسی کن.
7. نصب را کامل کن.
8. برنامه را اجرا کن و مطمئن شو درست نصب شده است.

## تمرین

با راهنمایی مربی، یکی از برنامه‌های امن و رایج را نصب کن:

- Google Chrome
- Mozilla Firefox
- VLC Media Player
- 7-Zip

## بهترین روش

هنگام نصب، فقط روی Next کلیک نکن. بعضی نصب‌کننده‌ها پیشنهاد نصب برنامه‌ی اضافی، تغییر مرورگر پیش‌فرض یا تغییر صفحه‌ی اصلی را می‌دهند. متن هر مرحله را بخوان.

# درس ۱۱ — حذف برنامه‌ها

حذف برنامه یا Uninstall برای زمانی است که دیگر به برنامه نیاز نداری یا برنامه باعث شلوغی، کندی یا مشکل شده است.

مزایا:

- آزاد شدن فضای ذخیره‌سازی
- کم شدن شلوغی سیستم
- کاهش برنامه‌های غیرضروری
- مدیریت بهتر کامپیوتر

## روش حذف برنامه در Windows

1. Settings را باز کن.
2. وارد Apps شو.
3. بخش Installed apps یا Apps & features را باز کن.
4. نام برنامه را پیدا کن.
5. گزینه‌ی Uninstall را انتخاب کن.
6. پیام‌ها را با دقت بخوان.
7. حذف را کامل کن.

## تمرین

- یک برنامه‌ی کوچک و بی‌خطر را با راهنمایی مربی نصب کن.
- آن را از بخش Apps پیدا کن.
- برنامه را Uninstall کن.
- بررسی کن که از فهرست برنامه‌ها حذف شده است.

## بهترین روش

برنامه‌هایی را که نمی‌شناسی بی‌دلیل حذف نکن. بعضی برنامه‌ها مربوط به درایورها، کارت گرافیک، صدا یا خود Windows هستند. اگر مطمئن نیستی، نام برنامه را جست‌وجو کن.

# درس ۱۲ — حساب‌های کاربری

User Account فضای شخصی هر کاربر در Windows است.

هر حساب می‌تواند داشته باشد:

- فایل‌های شخصی
- تنظیمات شخصی
- تصویر پس‌زمینه‌ی متفاوت
- رمز ورود جداگانه
- دسترسی‌های متفاوت

## انواع حساب کاربری

### Standard User

برای استفاده‌ی روزمره مناسب است. این حساب می‌تواند برنامه‌ها را اجرا کند و فایل‌های خودش را مدیریت کند، اما برای تغییرات مهم ممکن است به اجازه‌ی Administrator نیاز داشته باشد.

### Administrator

حساب Administrator اجازه‌ی تغییر تنظیمات مهم، نصب برنامه‌ها و مدیریت حساب‌های دیگر را دارد.

## چرا این تفاوت مهم است؟

دسترسی Administrator قدرت بیشتری دارد، اما اگر با بی‌دقتی استفاده شود، خطر بیشتری هم دارد. بعضی برنامه‌های مخرب هم تلاش می‌کنند اجازه‌ی Administrator بگیرند.

## تمرین

- نام حساب فعلی را بررسی کن.
- ببین حساب Microsoft است یا Local Account، اگر قابل مشاهده بود.
- وارد Settings > Accounts شو و بخش‌های اصلی را ببین.
- درباره‌ی رمز ورود و روش‌های Sign-in فکر کن.

## بهترین روش

برای کارهای روزمره لازم نیست همیشه تغییرات سیستمی انجام بدهی. وقتی Windows برای انجام کاری اجازه‌ی Administrator می‌خواهد، اول فکر کن آیا واقعاً خودت این کار را شروع کرده‌ای یا نه.

# درس ۱۳ — امنیت پایه در Windows

## رمز عبور قوی

رمز عبور خوب باید:

- طولانی باشد.
- حدس زدن آن سخت باشد.
- برای حساب‌های مهم تکراری نباشد.
- شامل ترکیبی از کلمه‌ها، عددها یا علامت‌ها باشد.

مثال آموزشی:

```text
Coffee!Train2026$Forest
```

این فقط یک مثال است و نباید دقیقاً از همین رمز استفاده کنی.

## Windows Security چیست؟

Windows Security ابزار داخلی Windows برای محافظت از کامپیوتر است.

این ابزار می‌تواند:

- فایل‌ها و برنامه‌های مشکوک را بررسی کند.
- وضعیت امنیت دستگاه را نشان دهد.
- از ویروس‌ها و تهدیدهای رایج جلوگیری کند.
- هشدارهای امنیتی نمایش دهد.

## مراقب این موارد باش

- دانلود برنامه از سایت‌های ناشناس
- باز کردن فایل‌های مشکوک
- کلیک روی لینک‌های عجیب
- وارد کردن رمز در سایت‌های نامطمئن
- وصل کردن فلش USB ناشناس
- نادیده گرفتن هشدارهای امنیتی Windows

## تمرین

- Windows Security را با Search پیدا کن.
- صفحه‌ی اصلی آن را باز کن.
- بخش Virus & threat protection را فقط مشاهده کن.
- بدون تغییر تنظیمات مهم، وضعیت کلی امنیت را بررسی کن.

## بهترین روش

اگر پیام امنیتی دیدی، آن را نادیده نگیر. متن پیام را بخوان، نام برنامه یا فایل را بررسی کن، و اگر مطمئن نیستی قبل از تأیید کردن جست‌وجو کن یا از فرد باتجربه کمک بگیر.

# تمرین ترکیبی مرحله ۲

تلاش کن با کمترین کمک این کارها را انجام بدهی:

1. Start Menu را باز کن.
2. با Search برنامه‌ی Calculator را پیدا و اجرا کن.
3. Notepad را اجرا کن.
4. مرورگر را اجرا کن.
5. بین برنامه‌ها با Taskbar جابه‌جا شو.
6. بین برنامه‌ها با `Alt + Tab` جابه‌جا شو.
7. یک پنجره را Minimize کن.
8. یک پنجره را Maximize کن.
9. یک پنجره را Restore کن.
10. دو پنجره را کنار هم قرار بده.
11. مرورگر یا Calculator را به Taskbar سنجاق کن.
12. Settings را باز کن.
13. تصویر پس‌زمینه را تغییر بده.
14. بین Light Mode و Dark Mode جابه‌جا شو.
15. بخش Apps را باز کن و فهرست برنامه‌ها را ببین.
16. Windows Update را باز کن و وضعیت آپدیت را بررسی کن.
17. Windows Security را باز کن و وضعیت کلی امنیت را مشاهده کن.

# پروژه‌ی پایانی مرحله ۲

برای پایان این مرحله، این کارها را مستقل انجام بده:

1. Start Menu را باز کن.
2. با Search برنامه‌ی Calculator را پیدا کن.
3. Calculator را اجرا کن.
4. Notepad را اجرا کن.
5. بین Calculator و Notepad با `Alt + Tab` جابه‌جا شو.
6. Notepad را به Taskbar سنجاق کن.
7. یک مرورگر را از Taskbar یا Start Menu اجرا کن.
8. تصویر پس‌زمینه‌ی دسکتاپ را تغییر بده.
9. Dark Mode یا Light Mode را فعال کن.
10. Settings را باز کن و وارد Apps شو.
11. یک برنامه‌ی تمرینی یا غیرضروری را پیدا کن.
12. با راهنمایی مربی، یک برنامه‌ی امن را نصب کن.
13. همان برنامه را Uninstall کن.
14. Windows Update را باز کن و وضعیت آپدیت را بررسی کن.
15. Windows Security را باز کن و وضعیت کلی امنیت را ببین.

مرحله ۲ را زمانی با موفقیت تمام کرده‌ای که بتوانی:

- برنامه‌ها و تنظیمات را سریع پیدا کنی.
- چند برنامه را هم‌زمان مدیریت کنی.
- پنجره‌ها را درست کنترل کنی.
- Taskbar را برای دسترسی سریع تنظیم کنی.
- ظاهر Windows را بدون کمک شخصی‌سازی کنی.
- برنامه‌ها را از منبع امن نصب و حذف کنی.
- حساب کاربری و دسترسی Administrator را در سطح پایه بفهمی.
- هشدارها و اصول امنیتی پایه را جدی بگیری.
