# مرحله ۴ — مهارت‌های اینترنت و امنیت آنلاین

امروزه بسیاری از کارهای روزمره آنلاین انجام می‌شوند: ارتباط با دیگران، آموزش، خرید، بانکداری، کارهای دولتی، درخواست شغل، ارسال مدارک و نگهداری فایل‌ها.

یاد گرفتن اینترنت فقط به معنی باز کردن سایت‌ها نیست. باید بتوانی اطلاعات درست را پیدا کنی، فایل‌ها را امن دانلود و آپلود کنی، ایمیل بفرستی، فرم‌ها را با دقت پر کنی و پیام‌ها یا سایت‌های مشکوک را تشخیص بدهی.

## در پایان این مرحله چه کاری می‌توانی انجام بدهی؟

بعد از تمرین‌های این مرحله، باید بتوانی:

- مفهوم ساده‌ی اینترنت، سایت، صفحه‌ی وب و لینک را توضیح بدهی.
- با مرورگر وب کار کنی.
- چند تب را هم‌زمان مدیریت کنی.
- در اینترنت بهتر و دقیق‌تر جست‌وجو کنی.
- URL و دامنه‌ی سایت را بشناسی.
- سایت‌های مهم را Bookmark کنی.
- فایل‌ها را امن دانلود و در جای درست ذخیره کنی.
- فایل‌ها را در ایمیل، فرم یا فضای ابری Upload کنی.
- ایمیل بسازی، ایمیل بفرستی و فایل پیوست کنی.
- فرم آنلاین را با دقت پر کنی.
- از فضای ابری برای نگهداری و اشتراک فایل استفاده کنی.
- فیشینگ، سایت جعلی، بدافزار و کلاهبرداری‌های رایج را تشخیص بدهی.
- رمز عبور قوی بسازی و از 2FA استفاده کنی.

## بهترین روش یادگیری در این مرحله

- هرجا چیزی مشکوک بود، توقف کن و بررسی کن.
- برای ورود به حساب‌های مهم، آدرس سایت را با دقت نگاه کن.
- فایل‌ها را فقط از منابع معتبر دانلود کن.
- قبل از ارسال فرم یا ایمیل، اطلاعات را دوباره بخوان.
- رمز عبور را تکراری انتخاب نکن.
- برای حساب‌های مهم مثل ایمیل و بانک، 2FA را فعال کن.

---

# درس ۱ — اینترنت چیست؟

اینترنت یک شبکه‌ی جهانی از کامپیوترها و دستگاه‌های متصل به هم است. این شبکه کمک می‌کند دستگاه‌ها در سراسر دنیا با هم اطلاعات رد و بدل کنند.

## مثال‌های استفاده از اینترنت

- تماشای ویدیو
- فرستادن ایمیل
- خواندن اخبار
- خرید آنلاین
- تماس تصویری
- یادگیری آنلاین
- ارسال مدارک
- استفاده از خدمات بانکی و دولتی

## چند واژه‌ی مهم

### Website

Website یا سایت مجموعه‌ای از صفحه‌های وب است.

مثال‌ها:

- Google
- Wikipedia
- YouTube
- سایت بانک
- سایت دانشگاه یا مدرسه

### Web Page

Web Page یک صفحه‌ی مشخص داخل یک سایت است؛ مثل صفحه‌ی تماس با ما، صفحه‌ی ورود یا یک مقاله.

### Link

Link چیزی است که روی آن کلیک می‌کنی و تو را به صفحه یا جای دیگری می‌برد.

## تمرین

سه سایت مختلف را باز کن و این موارد را تشخیص بده:

- نام سایت چیست؟
- هدف سایت چیست؟
- منوی اصلی یا بخش‌های مهم سایت کجاست؟

## بهترین روش

قبل از وارد کردن اطلاعات شخصی، اول مطمئن شو سایت همان سایتی است که می‌خواستی وارد آن شوی.

---

# درس ۲ — مرورگر وب

Browser یا مرورگر برنامه‌ای است که با آن سایت‌ها را باز می‌کنی.

## مرورگرهای رایج

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

## بخش‌های اصلی مرورگر

### Address Bar

جایی است که آدرس سایت را نشان می‌دهد یا می‌توانی آدرس سایت را داخل آن تایپ کنی.

مثال:

```text
https://www.wikipedia.org
```

### Tabs

تب‌ها کمک می‌کنند چند سایت را هم‌زمان باز نگه داری.

### Back

به صفحه‌ی قبلی برمی‌گردد.

### Forward

اگر برگشته باشی، دوباره به صفحه‌ی بعدی می‌رود.

### Refresh

صفحه را دوباره بارگذاری می‌کند.

## تمرین

این سایت‌ها را باز کن:

- Google
- Wikipedia
- YouTube

بعد این کارها را تمرین کن:

- Back
- Forward
- Refresh

## بهترین روش

آدرس سایت‌های مهم را در Address Bar بررسی کن. گاهی نتیجه‌های جست‌وجو یا تبلیغات شبیه سایت اصلی هستند اما آدرس متفاوتی دارند.

---

# درس ۳ — تب‌ها و کار هم‌زمان در مرورگر

بدون تب، معمولاً فقط یک سایت را می‌بینی. با تب‌ها می‌توانی چند سایت را هم‌زمان باز نگه داری و بین آن‌ها جابه‌جا شوی.

## میانبرهای مهم تب‌ها

باز کردن تب جدید:

```text
Ctrl + T
```

بستن تب:

```text
Ctrl + W
```

بازگرداندن تب بسته‌شده:

```text
Ctrl + Shift + T
```

رفتن به تب بعدی:

```text
Ctrl + Tab
```

## تمرین

- پنج سایت را در پنج تب جداگانه باز کن.
- بین تب‌ها جابه‌جا شو.
- یک تب را ببند.
- همان تب را با `Ctrl + Shift + T` برگردان.

## بهترین روش

تب‌های خیلی زیاد تمرکز را کم می‌کنند. وقتی کار یک تب تمام شد، آن را ببند.

---

# درس ۴ — موتور جست‌وجو

Search Engine یا موتور جست‌وجو کمک می‌کند اطلاعات را در اینترنت پیدا کنی.

## موتورهای جست‌وجوی رایج

- Google
- Bing
- DuckDuckGo

## جست‌وجوی بهتر

جست‌وجوی ضعیف:

```text
computer problem
```

جست‌وجوی بهتر:

```text
Windows 11 microphone not working
```

مثال دیگر:

```text
best free pdf reader windows
```

به جای:

```text
pdf thing
```

## تمرین

این موارد را جست‌وجو کن و نتیجه‌ها را مقایسه کن:

- آب‌وهوای شهر خودت
- PDF reader
- یک دستور آشپزی
- آموزش ساده‌ی کامپیوتر

## بهترین روش

هرچه سؤال دقیق‌تر باشد، نتیجه بهتر است. از کلمه‌های مشخص مثل نام برنامه، نسخه‌ی Windows یا نوع مشکل استفاده کن.

---

# درس ۵ — شناخت URL

URL همان آدرس سایت است.

مثال:

```text
https://www.example.com
```

## بخش‌های اصلی URL

```text
https://www.example.com/page
```

### https

نشان می‌دهد اتصال امن‌تر است. برای سایت‌های مهم مثل ایمیل، بانک و خرید آنلاین، وجود `https` مهم است.

### Domain

هویت اصلی سایت است.

```text
example.com
```

### Page

صفحه‌ی خاصی از سایت را نشان می‌دهد.

## تمرین

سه سایت را باز کن و این موارد را بررسی کن:

- دامنه‌ی سایت چیست؟
- آیا از `https` استفاده می‌کند؟
- آیا آدرس با چیزی که انتظار داشتی هماهنگ است؟

## بهترین روش

برای سایت‌های مهم، فقط به ظاهر صفحه اعتماد نکن. دامنه‌ی سایت را هم با دقت نگاه کن.

---

# درس ۶ — Bookmark

Bookmark یعنی ذخیره کردن آدرس یک سایت برای استفاده‌ی بعدی.

## چرا Bookmark مفید است؟

- دسترسی سریع‌تر
- نیاز کمتر به جست‌وجوی دوباره
- نظم بهتر برای سایت‌های مهم

## ساختار پیشنهادی

```text
Bookmarks
├── Learning
├── News
├── Work
└── Shopping
```

## تمرین

این سایت‌ها را Bookmark کن:

- یک سایت خبری معتبر
- یک سایت آموزشی
- یک سایت ویدیویی مورد علاقه

## بهترین روش

برای سایت‌های مهم مثل ایمیل، بانک یا پنل کاری، استفاده از Bookmark مطمئن بهتر از کلیک روی لینک‌های ناشناس است.

---

# درس ۷ — دانلود فایل

Download یعنی فایل از اینترنت به کامپیوتر تو منتقل شود.

## فایل‌های رایج برای دانلود

- PDF
- عکس
- ویدیو
- نرم‌افزار
- سندها

## قانون‌های دانلود امن

فقط از این منابع دانلود کن:

- سایت رسمی برنامه یا سازمان
- منابع معتبر و شناخته‌شده

دوری کن از:

- پنجره‌های تبلیغاتی مشکوک
- دکمه‌های Download ناشناس
- فایل‌هایی که از پیام‌های عجیب آمده‌اند
- سایت‌هایی که چند دکمه‌ی دانلود گیج‌کننده دارند

## تمرین

- یک فایل PDF آموزشی امن دانلود کن.
- یک عکس تمرینی دانلود کن.
- فایل‌ها را از Downloads به پوشه‌ی مناسب منتقل کن.

## بهترین روش

بعد از دانلود، فایل را بررسی کن. اگر لازم است نگه داری، آن را به پوشه‌ی درست منتقل کن؛ اگر لازم نیست، حذفش کن.

---

# درس ۸ — آپلود فایل

Upload یعنی فایل از کامپیوتر تو به اینترنت فرستاده شود.

## مثال‌ها

- پیوست کردن فایل در ایمیل
- ارسال رزومه در فرم استخدام
- ذخیره فایل در فضای ابری
- ارسال عکس در شبکه‌های اجتماعی

## تمرین

با راهنمایی مربی، این فایل‌ها را در یک سرویس تمرینی، ایمیل یا فضای ابری Upload کن:

- یک عکس
- یک PDF

## بهترین روش

قبل از Upload، فایل را باز کن و مطمئن شو همان فایلی است که می‌خواهی ارسال کنی. اشتباه فرستادن فایل یکی از خطاهای رایج است.

---

# درس ۹ — ایمیل

Email یا ایمیل برای ارتباط، کار، ثبت‌نام در حساب‌ها و ارسال فایل استفاده می‌شود.

## سرویس‌های رایج ایمیل

- Gmail
- Outlook
- Yahoo Mail

## بخش‌های اصلی ایمیل

### Inbox

ایمیل‌های دریافت‌شده.

### Sent

ایمیل‌های ارسال‌شده.

### Drafts

ایمیل‌های نیمه‌کاره که هنوز ارسال نشده‌اند.

### Trash

ایمیل‌های حذف‌شده.

## تمرین

با راهنمایی مربی:

- یک حساب ایمیل بساز یا وارد حساب تمرینی شو.
- یک ایمیل ساده بفرست.
- یک ایمیل همراه با فایل پیوست بفرست.

## بهترین روش

برای ایمیل‌های رسمی، موضوع واضح بنویس، متن کوتاه و محترمانه داشته باش و قبل از ارسال، فایل پیوست را دوباره بررسی کن.

---

# درس ۱۰ — فرم‌های آنلاین

Online Form یا فرم آنلاین برای جمع‌آوری اطلاعات در سایت‌ها استفاده می‌شود.

مثال‌ها:

- فرم ثبت‌نام
- فرم نظرسنجی
- فرم درخواست شغل
- فرم ارسال مدارک

## فیلدهای رایج

- Name
- Email
- Phone number
- Address
- File upload

## تمرین

یک فرم تمرینی را پر کن و قبل از Submit این موارد را بررسی کن:

- نام درست نوشته شده است؟
- ایمیل درست است؟
- فایل درست پیوست شده است؟
- اطلاعات اضافی یا حساس وارد نکرده‌ای؟

## بهترین روش

قبل از زدن Submit، یک بار کل فرم را از بالا تا پایین بخوان. بعد از ارسال بعضی فرم‌ها، اصلاح اطلاعات سخت می‌شود.

---

# درس ۱۱ — فضای ابری

Cloud Storage یعنی فایل‌ها روی سرورهای آنلاین نگهداری می‌شوند و با اینترنت از دستگاه‌های مختلف قابل دسترسی هستند.

## مزیت‌ها

- پشتیبان‌گیری از فایل‌ها
- دسترسی از چند دستگاه
- اشتراک‌گذاری راحت‌تر
- کاهش خطر گم شدن فایل‌ها

## سرویس‌های رایج

- Google Drive
- OneDrive
- Dropbox
- iCloud Drive

## تمرین

با راهنمایی مربی:

- یک سند را Upload کن.
- یک عکس را Upload کن.
- یک لینک اشتراک‌گذاری بساز.

## بهترین روش

وقتی لینک اشتراک‌گذاری می‌سازی، دقت کن لینک برای چه کسانی قابل مشاهده است. فایل‌های شخصی یا حساس را عمومی نکن.

---

# درس ۱۲ — امنیت آنلاین

قانون طلایی:

اگر چیزی مشکوک به نظر می‌رسد، توقف کن و بررسی کن.

## تهدیدهای رایج

### Phishing

فیشینگ پیام یا صفحه‌ی جعلی است که تلاش می‌کند اطلاعات تو را بدزدد.

مثال:

```text
Your account has been suspended!
Click here immediately!
```

### سایت جعلی

سایتی که شبیه سایت اصلی طراحی شده اما آدرس آن فرق دارد.

همیشه بررسی کن:

- دامنه‌ی سایت درست باشد.
- اتصال `https` وجود داشته باشد.
- متن‌ها و ظاهر سایت غیرعادی نباشد.

### Malware

بدافزار نرم‌افزار مخرب است و می‌تواند:

- اطلاعات را بدزدد.
- فایل‌ها را خراب کند.
- کامپیوتر را کند کند.
- پیام‌ها یا تبلیغات عجیب نمایش دهد.

## تمرین

دو نمونه صفحه یا پیام را مقایسه کن:

- یکی معتبر
- یکی مشکوک یا آموزشی

نشانه‌های خطر را پیدا کن.

## بهترین روش

روی لینک‌های عجیب در ایمیل، پیامک یا شبکه‌های اجتماعی سریع کلیک نکن. اگر پیام مهم به نظر می‌رسد، خودت آدرس سایت اصلی را تایپ کن یا از Bookmark مطمئن استفاده کن.

---

# درس ۱۳ — امنیت رمز عبور

رمز عبور خوب باید:

- طولانی باشد.
- برای هر حساب مهم متفاوت باشد.
- حدس زدن آن سخت باشد.
- ترکیبی از کلمه‌ها، عددها یا علامت‌ها داشته باشد.

مثال آموزشی:

```text
River!Train$Coffee2026
```

این فقط یک مثال است و نباید دقیقاً از همین رمز استفاده کنی.

## رمزهای ضعیف

```text
123456
password
qwerty
birthday
```

## Password Manager چیست؟

Password Manager ابزاری است که رمزها را امن نگه می‌دارد و کمک می‌کند برای هر حساب رمز متفاوت داشته باشی.

نمونه‌ها:

- Bitwarden
- 1Password
- Dashlane
- Google Password Manager

## تمرین

سه نمونه رمز را بررسی کن و بگو کدام قوی‌تر است و چرا. رمز واقعی خودت را در تمرین ننویس.

## بهترین روش

رمز ایمیل بسیار مهم است، چون خیلی از حساب‌های دیگر به ایمیل وصل هستند. برای ایمیل رمز قوی و 2FA داشته باش.

---

# درس ۱۴ — احراز هویت دو مرحله‌ای

2FA یا احراز هویت دو مرحله‌ای یک لایه‌ی امنیتی اضافه است.

برای ورود، معمولاً دو چیز لازم می‌شود:

1. رمز عبور
2. روش تأیید دوم

## نمونه‌های روش دوم

- کد داخل برنامه‌ی موبایل
- کد پیامک
- کلید امنیتی
- تأیید روی دستگاه دیگر

## چرا 2FA مهم است؟

اگر رمز عبور تو لو برود، 2FA می‌تواند جلوی ورود افراد دیگر را بگیرد.

## تمرین

با راهنمایی مربی، 2FA را روی یک حساب تمرینی یا حسابی که مناسب است فعال کن.

## بهترین روش

برای حساب‌های مهم مثل ایمیل، بانک، فضای ابری و شبکه‌های اجتماعی از 2FA استفاده کن.

---

# درس ۱۵ — تشخیص کلاهبرداری آنلاین

کلاهبرداری‌های آنلاین معمولاً تلاش می‌کنند تو را عجول، ترسان یا هیجان‌زده کنند.

## نشانه‌های رایج

### درخواست رمز عبور

شرکت‌های معتبر معمولاً از طریق ایمیل از تو رمز عبور نمی‌خواهند.

## تمرین

چند پیام نمونه را بررسی کن و برای هرکدام بگو:

- آیا عجله ایجاد می‌کند؟
- آیا ترس ایجاد می‌کند؟
- آیا لینک مشکوک دارد؟
- آیا اطلاعات حساس می‌خواهد؟

## بهترین روش

وقتی پیام خیلی خوب، خیلی فوری یا خیلی ترسناک به نظر می‌رسد، با دقت بیشتری بررسی کن.

# میانبرهای مفید مرورگر

| میانبر | کار |
| --- | --- |
| `Ctrl + T` | باز کردن تب جدید |
| `Ctrl + W` | بستن تب |
| `Ctrl + Shift + T` | بازگرداندن تب بسته‌شده |
| `Ctrl + L` | رفتن به Address Bar |
| `Ctrl + F` | جست‌وجو داخل صفحه |
| `Ctrl + D` | Bookmark کردن صفحه |
| `Ctrl + Tab` | رفتن به تب بعدی |
| `F5` | Refresh کردن صفحه |

# تمرین ترکیبی مرحله ۴

تلاش کن با کمترین کمک این کارها را انجام بدهی:

1. یک مرورگر را باز کن.
2. درباره‌ی یک دستور آشپزی جست‌وجو کن.
3. سه تب باز کن.
4. بین تب‌ها جابه‌جا شو.
5. یک سایت مفید را Bookmark کن.
6. یک PDF امن دانلود کن.
7. PDF را به Documents منتقل کن.
8. یک ایمیل ساده بنویس.
9. یک فایل را به ایمیل پیوست کن.
10. یک فایل را در فضای ابری Upload کن.
11. لینک اشتراک‌گذاری بساز.
12. یک URL را بررسی کن و دامنه‌ی آن را تشخیص بده.
13. سه نشانه‌ی فیشینگ را در یک پیام نمونه پیدا کن.

# چک‌لیست عملی مرحله ۴

وقتی کنار هر مورد بتوانی تیک بزنی، یعنی مرحله ۴ را خوب تمرین کرده‌ای:

- [ ] سایت‌ها را باز می‌کنم.
- [ ] از تب‌های مرورگر استفاده می‌کنم.
- [ ] با کلمه‌های دقیق جست‌وجو می‌کنم.
- [ ] URL و دامنه‌ی سایت را تشخیص می‌دهم.
- [ ] سایت‌ها را Bookmark می‌کنم.
- [ ] فایل‌ها را امن دانلود می‌کنم.
- [ ] فایل‌ها را Upload می‌کنم.
- [ ] ایمیل می‌فرستم.
- [ ] فایل را به ایمیل پیوست می‌کنم.
- [ ] فرم آنلاین را با دقت پر می‌کنم.
- [ ] از فضای ابری استفاده می‌کنم.
- [ ] لینک اشتراک‌گذاری می‌سازم.
- [ ] فیشینگ را تشخیص می‌دهم.
- [ ] رمز عبور قوی می‌سازم.
- [ ] 2FA را می‌شناسم و برای حساب‌های مهم فعال می‌کنم.
- [ ] نشانه‌های کلاهبرداری آنلاین را تشخیص می‌دهم.

# پروژه‌ی پایانی مرحله ۴

برای پایان این مرحله، این کارها را مستقل انجام بده:

1. یک مرورگر را باز کن.
2. درباره‌ی یک دستور آشپزی یا موضوع آموزشی جست‌وجو کن.
3. سه تب باز کن.
4. یک سایت مفید را Bookmark کن.
5. یک PDF امن دانلود کن.
6. فایل PDF را به Documents منتقل کن.
7. یک حساب ایمیل بساز یا وارد حساب تمرینی شو.
8. یک ایمیل همراه با فایل پیوست بفرست.
9. یک فایل را در فضای ابری Upload کن.
10. فایل را با لینک اشتراک‌گذاری کن.
11. 2FA را روی یک حساب مناسب یا تمرینی فعال کن.
12. سه نشانه‌ی فیشینگ را در یک پیام نمونه توضیح بده.

## معیار قبولی

مرحله ۴ را زمانی با موفقیت تمام کرده‌ای که بتوانی:

- با اطمینان در اینترنت حرکت کنی.
- اطلاعات را با جست‌وجوی مناسب پیدا کنی.
- از مرورگر، تب‌ها و Bookmark استفاده کنی.
- ایمیل را مستقل استفاده کنی.
- فایل‌ها را امن دانلود و Upload کنی.
- فرم‌های آنلاین را با دقت پر کنی.
- مفهوم فضای ابری و اشتراک‌گذاری فایل را بفهمی.
- از خودت در برابر فیشینگ، سایت جعلی و کلاهبرداری‌های رایج محافظت کنی.
- رمزهای قوی و 2FA را برای حساب‌های مهم جدی بگیری.

## زمان پیشنهادی

برای بیشتر افراد، این مرحله با **۱۵ تا ۲۵ ساعت آموزش و تمرین عملی** قابل انجام است.

اگر هنوز در مدیریت فایل‌ها، Downloads یا پیدا کردن فایل‌ها راحت نیستی، قبل از ادامه چند تمرین از مرحله ۳ را دوباره مرور کن.
